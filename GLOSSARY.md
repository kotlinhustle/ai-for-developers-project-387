# Календарь звонков

Сервис для бронирования звонков: владельцы публикуют свой календарь,
гости записываются на звонки. Этот глоссарий фиксирует язык продукта.

## Язык

**Владелец**:
Пользователь сервиса, который задаёт календарь и принимает звонки.
_Избегать_: организатор, хост, эксперт, специалист

**Гость**:
Посетитель, который бронирует звонок у владельца.
_Избегать_: клиент, пользователь, заказчик

**Главная страница**:
Публичная витрина сервиса, которая рассказывает о продукте и ведёт к записи.
_Избегать_: лендинг, домашняя страница, index

**Страница записи**:
Страница, на которой гость бронирует звонок у владельца.
_Избегать_: страница бронирования, booking

**Часовой пояс**:
Пояс владельца, в котором заданы рабочие часы и определяется текущая дата.
_Избегать_: таймзона, timezone, GMT-смещение

**Рабочие часы**:
Интервалы по дням недели, в которые владелец принимает звонки.
_Избегать_: график, расписание, часы работы

**Окно записи**:
Диапазон дат, внутри которого гость может бронировать слоты.
_Избегать_: период, горизонт

**Тип встречи**:
Описание бронируемого звонка: название, описание и длительность.
_Избегать_: тип звонка, вид встречи

**Слот**:
Интервал времени, который владелец открывает для записи на звонок.
_Избегать_: окно, таймслот, время

**Свободный слот**:
Слот, который целиком помещается в рабочие часы и не пересекается с существующими бронями.
_Избегать_: доступное время, окно

**Запись на звонок**:
Подтверждённая договорённость о звонке между гостем и владельцем в выбранном слоте.
_Избегать_: бронь, бронирование, встреча
