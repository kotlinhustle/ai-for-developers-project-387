# Главная страница — витрина сервиса для гостей

Первая фича — главная страница «Календаря звонков». Решили: главная — это публичная витрина платформы, нацеленная на гостя, с одним CTA «Записаться на звонок», ведущим на страницу записи. Отдельного фаннела для владельцев (регистрация, создание календаря) и блоков FAQ / отзывы / тарифы на главной нет.

Причина: требование — «рассказывать про сервис и вести на страницу записи»; лишние ветки раздувают первую фичу. Пересмотрим, когда появится продуктовая необходимость привлекать владельцев или добавлять маркетинговые блоки.
