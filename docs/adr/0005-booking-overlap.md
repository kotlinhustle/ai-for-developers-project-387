# Пересечения броней: интервальное пересечение

Запрет «две записи на одно время, включая разные типы встреч» реализуем как непустое пересечение интервалов `[начало, конец)` для любых типов: новая бронь отклоняется, если `start1 < end2` и `start2 < end1` с любой существующей. Длительность встречи не обязана быть кратной шагу сетки, поэтому встреча может занимать несколько ячеек.

Причина: интервальное пересечение — самый общий критерий и прямо выражает требование; кратность 30 минутам ограничивала бы владельца без пользы. Отвергнуто: сравнение только по времени начала (пропускает частичные наложения при разных длительностях).
