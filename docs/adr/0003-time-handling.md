# Время: UTC-инстанты и фиксированный пояс владельца

Для «Календаря звонков» решили: время начала и конца встречи хранится в UTC, а `zoneId` — в настройках владельца. Рабочие часы 09:00–18:00 задаются в поясе владельца; для учебного проекта пояс фиксирован — `Asia/Yerevan`. Гость видит время в поясе владельца, пояс явно подписан рядом с календарём; текущая дата для окна записи (14 дней) также определяется в поясе владельца.

Причина: один владелец и отсутствие аккаунтов гостя — фиксированный пояс убирает неоднозначность, а хранение UTC + `zoneId` оставляет путь к конвертации в пояс гостя без миграции данных. Отвергнуто: хранение локального времени без пояса (ломается на переходах) и гостевой пояс на этом этапе (не нужен, усложняет MVP).
