# API-контракт: минимальный REST, описан в TypeSpec

Контракт описывается в TypeSpec и генерируется в OpenAPI. Набор эндпоинтов минимален: публичные `GET /meeting-types`, `GET /meeting-types/{id}/slots?from&to`, `POST /bookings`; владельческие `POST /meeting-types`, `GET /bookings`. Время — ISO-8601 в UTC, пояс владельца отдаётся отдельным полем; ошибки — `409 Conflict` при наложении, `422` при валидации.

Причина: покрывает ровно требования владельца и гостя. Отвергнуто: `PATCH`/`DELETE` типов встреч, отмена брони, пагинация/фильтры — вне текущего этапа (см. «Not yet specified» карты).
