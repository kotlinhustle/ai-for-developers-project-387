# Выбор БД: H2 без `DB_URL`, Postgres с `DB_URL`

Приложение выбирает базу данных до старта контекста. Если задана переменная `DB_URL` (плюс `DB_USER`, `DB_PASSWORD`), используется PostgreSQL с миграциями Flyway и проверкой схемы (`ddl-auto=validate`). Если `DB_URL` не задана, поднимается встроенная in-memory H2: схема создаётся из сущностей, Flyway отключён. Выбор делает `DatabaseEnvironmentPostProcessor`.

Причина: образ должен стартовать без внешней БД при запуске «только с `PORT`» (это делает автопроверка `hexlet-check`), а деплой — работать на полноценном PostgreSQL с ограничением наложений (ADR-0006). Отвергнуто: требовать БД всегда (образ не стартует без Postgres) и использовать H2 на деплое вместо Postgres (теряется exclusion constraint).
